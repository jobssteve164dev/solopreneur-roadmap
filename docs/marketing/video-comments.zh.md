# SoloMap 视频评论区宣传文案集锦 (防引流举报版)

本篇文档提供了一批专门为 Bilibili (B站)、YouTube、抖音、小红书、微信视频号等视频平台定制的**评论区宣传文案**。
所有文案均经过精心打磨，采用**真实开发者视角**，结合行业痛点、技术讨论与工具评测，避免明显的硬广推销和营销词汇，以实现“润物细无声”的自来水式推广，最大程度避免被系统吞评或被用户举报为引流小广告。

---

## 🧭 防引流与免举报核心策略 (Anti-Spam Strategy)

要想评论不被举报、不被平台折叠，必须遵循以下几个原则：

1. **痛点切入，不贴链接**：绝对不要在首层评论（一楼）贴任何 VS Code Marketplace 链接或 GitHub 链接。如果有人追问“怎么搜”、“怎么用”，再在回复（二楼）中给出插件名字：`SoloMap` 或者是 `SZLK.solopreneur-roadmap`。
2. **结合主流，伪装讨论**：将本插件与当前最火的热点工具（如 `Claude Code`、`agy`、`Copilot CLI`）进行绑定讨论，让评论看起来像是一个有深度、有建设性的技术分享。
3. **真实口语化，杜绝排版怪**：评论字数不要过多，多用程序员日常的“黑话”和语气助词（如“确实”、“太真实了”、“痛点握手”、“折腾党福音”），不要使用小红书长文格式或大面积的 emoji。
4. **一问一答（钓鱼互动）**：用小号或让朋友帮忙，以“提问-解答”的互动形式在热门视频下“双簧”带出插件。

## ✍️ 评论文案模板库 (Comment Templates)

### 📂 分类一：本地 CLI Agent 讨论区（B站/YouTube 极客区常用）
> **适用场景**：关于 Claude Code、agy、Copilot CLI 体验评测的视频下，或者是讨论“为什么终端 Agent 效率更高/更难用”的视频。

#### 📝 模板 1.1：痛点共鸣与辅助看板
> 确实，本地跑 Claude Code 速度和智商都拉满了，但就是终端里一直刷 log，过一会就忘了上一阶段改了什么。现在我是配合 VS Code 里的 SoloMap 一起用，把步骤拆成 roadmap.csv 扔 Git 里，然后在 SoloMap 看板上直接一键调本地 CLI，这样终于有开发全局观了，不用一直在终端里瞎忙活。

#### 📝 模板 1.2：上下文防断片讨论
> Claude Code 好用是好用，但最怕它写着写着上下文超限或者失忆。我们现在用 agy 也是这毛病。感觉 SoloMap 那个“环节记忆交接”的设计思路挺合理的，每次唤醒 Agent 前自动把步骤上下文（step-memory）打个包喂给它，Agent 进去后带着标准干活，不容易跑偏。

#### 📝 模板 1.3：主副 Agent 双智能体协作
> 没人试试“主副 Agent”搭配干活吗？我最近用 SoloMap 插件做调度，主 Agent 负责嘎嘎写代码（比如 agy），副 Agent（比如 Claude）只读跑 review 代码门禁，质量直接上了一个台阶。比单干靠谱多了。

### 📂 分类二：吐槽“AI 乱聊/失忆地狱”共鸣型（广泛适用）
> **适用场景**：程序员吐槽“AI 编码弄坏旧功能”、“对话窗口太多找不到了”、“AI 越聊越蠢”等吐槽向视频。

#### 📝 模板 2.1：吐槽多对话框乱套
> 哈哈太真实了！之前我做个副业，光是跟 AI 聊天就开了 20 多个窗口，过了周末直接失忆，根本不知道改了哪儿。后来果断把项目路线图落成 Git 里的 CSV，用 SoloMap 这个 VS Code 看板管。AI 改了哪一步一目了然，拯救了我的脑容量。

#### 📝 模板 2.2：AI 乱改代码与 Git Diff
> 被 AI 乱改代码折腾过好多次，每次跑完都不知道它动了什么。我现在都是用本地插件 SoloMap 管理，路线图直接和 Git 绑定，每次状态变更就是一个纯文本 diff，Git 提交历史里清清楚楚，再也不怕黑盒执行了。

#### 📝 模板 2.3：治好开发拖延症
> 感觉 AI 编程最怕没有节奏感。经常是一直在微调一些细节，反而忘了主线任务。推一下 Build-Sell-Learn 的闭环思路，我用 SoloMap 把想法拆细之后，就只盯着看板上当前那个节点让 Agent 冲，交付效率提高了一倍。

### 📂 分类三：隐私/本地优先敏感型（硬核程序员区）
> **适用场景**：讨论 Cursor/Devin 涨价、强制上传代码、代码隐私泄露、公司禁用云端 AI 等话题。

#### 📝 模板 3.1：拒绝云端锁死与昂贵收费
> 说实话，现在的云端 AI IDE 确实好用，但每个月扣月租还是有点肉疼，而且最主要是公司不给传代码到外网。我现在全套都在本地玩，用本地免费的 CLI 配合 VS Code 的 SoloMap，数据都在项目根目录 `.solopreneur/` 下，全程断网也能跑，隐私直接拉满。

#### 📝 模板 3.2：Git 友好型极简配置
> 很多工具强行绑定云端数据库，换台电脑数据就丢了。SoloMap 这种把路线图存成 `roadmap.csv` 扔在仓库里的做法真的对 Git 强迫症极其友好，Git Clone 下来直接就是之前的状态，不用配置任何云端后端。

#### 📝 模板 3.3：本地党的最爱
> 折腾了一圈，还是回到了本地 CLI。Claude Code 配合 SoloMap 真的是程序员的白嫖党/本地党福音。任务执行全在 VS Code 集成终端里，完全透明，再也不怕云端 Agent 在后台偷偷乱扣额度了。

### 📂 分类四：独立开发/副业推进痛点型（搞钱/创业视频区）
> **适用场景**：搞钱、程序员副业、个人创业、如何快速上线一个 SaaS 产品的视频。

#### 📝 模板 4.1：小步快跑，Build to Sell
> 独立开发最大的坎儿不是技术，而是“一直停在 Build 阶段”。很多程序员写着写着就陷进技术重构里了。SoloMap 那个把路线图强行拆成 Build -> Sell -> Learn -> Improve 的路子太对了，提醒你写完就得去卖，收集反馈再改进。强烈建议想做副业的程序员试试这种推进模型。

#### 📝 模板 4.2：单兵作战的驾驶舱
> 一个人做项目，既要当产品又要当开发还要做运营，脑子容易爆。VS Code 里的 SoloMap 相当于给单兵作战配了个仪表盘，把杂乱的 AI 聊天穿针引线变成了结构化路线图，能帮你省去很多无意义的反复沟通。

#### 📝 模板 4.3：冷启动利器
> 做副业冷启动时，脑子一团乱麻。用这插件直接在 VS Code 里写一句话构想，让 AI 自动生成第一版 `roadmap.csv` 看板，直接把宏大目标拆成一键运行的子任务，跟着看板一步步走就行，非常适合验证 MVP。

## 💡 使用小贴士与变体技巧 (Tips & Best Practices)

1. **错字防屏蔽**：某些平台对特定敏感词屏蔽严格。如果直接发“SoloMap”被吞，可以尝试写成 `Solo Map`、`索罗Map` 或 `VS Code 那个路线图插件`。
2. **结合时间戳**：如果在博主提到某个痛点（如 03:45 提到 AI 容易改错代码）时发表评论，可以加上时间戳，如 `03:45 哈哈太真实了，之前我也遇到过...后来用 SoloMap 看板辅助本地 CLI 好多了`。这种带时间戳的评论不仅容易上热门，而且自来水感极强。
3. **点赞与互动维护**：评论发出去后，可以找朋友点赞或在下方回复“握手”、“这个思路确实可以”，提高评论的权重，让其上升到前排。
