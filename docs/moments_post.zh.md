## ✍ 朋友圈文案选项

### 选项一：痛点共鸣与故事型（推荐 👍）
> **适合人群**: 微信里有很多独立开发者、Indie Hacker、AI 编码爱好者的圈子。
> **侧重点**: 直击“AI 写了堆积如山的代码，项目却卡在半路/没法上线”的痛点。

💬 **文案内容**：
```text
用 AI 写代码，最后都变成“烂尾楼”了？🤔

这大概是每个独立开发者/Indie Hacker 都在经历的痛：
1️⃣ 脑子一热，让 AI 写了上千行代码；
2️⃣ 隔了几天没看，重新打开项目，上下文全丢了；
3️⃣ 堆满了 TODO 和 Chat 历史，却不知道“下一步该干什么”；
4️⃣ 产品看似动了，但卡在客户发现和发布前夕，迟迟无法面世……

AI 编码时代，我们不缺代码生成器，缺的是一个【项目执行驾驶舱】！

我做了一个 VS Code 本地优先插件 —— 🛠 SoloMap 🗺
✨ 专为独立开发者设计，将“客户发现、MVP 研发、营销推广、反馈复盘”串成一张可视化路线图。
✨ 每一个 Roadmap 节点都是一个 AI Task Flow，直接一键调度你本地的 AI Agent（支持 Antigravity, Claude Code, Codex, Cline 等），自动记录每次执行日志和上下文 handoff，让项目真正做到 Git 跟踪、本地可控！

现在我们刚刚进入“客户验证”阶段，诚邀 15 位正在用 AI 推进独立项目的朋友深度访谈/早期试用！
如果你经常因为“上下文丢失、下一步不清晰”而卡住，欢迎私信我聊聊！👇

（配图：resources/solomap_intro.png）
```

### 选项二：硬核技术与本地优先型（Geek Style）
> **适合人群**: 极客、技术至上的独立开发者。
> **侧重点**: 强调本地优先、Git 友好、不依赖云端，以及直接在 VS Code 里调度本地 CLI Agent 的极简工作流。

💬 **文案内容**：
```text
【独立开发者的新玩具】做了一个本地优先（Local-First）的 VS Code 插件：SoloMap。

AI Agent 写代码很爽，但怎么跟我们的项目管理、版本控制和发布节奏无缝结合？
SoloMap 给你答案：
- 📂 所有数据（Roadmap.csv、运行日志、交接上下文）全在项目根目录 .solopreneur/ 下，Git 友好，不存第三方服务器。
- ⚙️ 无缝集成你已有的 CLI Agent（Antigravity / agy / Claude Code / Codex / Cline...），在 VS Code 里面直接派发任务、追踪执行。
- 📊 清晰的四阶段路线图（问题发现 -> MVP -> 营销 -> 反馈），阻止 AI 项目退化成纯工程任务，确保每一步都在走向交付。

目前正在进行早期用户招募，欢迎找我拿 VSIX 包安装试用！如果你也想让你的 AI 编码过程更加井然有序，私信交流！

（配图：resources/solomap_intro.png）
```

> **侧重点**: 突出视觉震撼的介绍图，快速引导私信招募。

💡 AI 帮你写完代码，下一步该做什么？

把你的产品想法，在 VS Code 里变成一张可视化的 AI 可执行路线图。

✅ 本地优先：Git 托管所有执行轨迹，数据绝不离身。
✅ 闭环交付：融合“构建、销售、学习、改进”完整闭环。

🔥 第一批早期体验官招募中，欢迎私信/扣 1 获取本地安装包！让我们一起把想法变成可运行的真实产品。

## 💡 如何使用这些材料推进“客户发现”？

1. **搭配访谈表使用**:
   在朋友圈吸引到感兴趣的开发者后，可以使用 [docs/customer_discovery.zh.md](file:///home/ubuntu/project/solopreneur-roadmap/docs/customer_discovery.zh.md) 中的 **10 个访谈问题** 进行一对一私聊或语音走查。
2. **记录用户反馈**:
   将访谈得到的真实卡点和对 SoloMap 的反应，记录到 `customer_discovery.zh.md` 底部的**反馈记录表**中，以便后续通过 SoloMap 的 `調整路线图 / Revise Roadmap` 功能对产品方向进行迭代。
