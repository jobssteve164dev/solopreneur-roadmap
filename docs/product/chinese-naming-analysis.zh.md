# SoloMap 中文命名方案策划与分析

本报告立足于对 **SoloMap** 项目文档（包括商业计划书、核心方法论、架构设计与本地数据结构）的深入理解，针对独立开发者（Solo Developer / Solopreneur / Indie Hacker）这一核心受众，就“中文名称”进行深度头脑风暴与品牌定位分析。

---

## 🧭 项目内核与设计切入点

在进行中文命名之前，我们需要明确 SoloMap 在用户心智和技术实现上的核心特质：

1. **用户画像**：独自一人战斗的软件创业者（Solo Founder）、独立开发者、Indie Hacker。他们充满创造力，但也极易在琐碎的代码、AI 乱聊、中断的上下文中迷失。
2. **产品定位**：**不是“AI 编码助手”，而是“项目执行驾驶舱”**。它处于 AI 终端 CLI（如 Claude Code, agy）之上，负责给 AI 提供业务上下文（Handover）与交付路线图（Roadmap）。
3. **技术特质**：本地优先（Local-first）、Git 友好（CSV 存储）、注重经验沉淀（跨项目记忆库）与高审美（VS Code 可视化面板）。
4. **核心痛点**：对话碎片化、黑盒执行失控、项目丢失方向。

---

## 🎨 中文命名方案矩阵

我们将命名方案归纳为三个主要品牌维度，以适应不同的市场传播偏向：

### 维度 A：艺术与心智共鸣（推荐）—— 强调“一人调度、优雅编排”
> **AI 时代，独立开发者不再是干脏活累活的码农，而是指挥多智能体的乐团总指挥。**

#### 1. 独奏 (Soloist / SoloConcert)
*   **字面拆解**：“独”对应 Solo，“奏”代表协同与执行。
*   **品牌寓意**：你是一人公司，但你不是孤立无援。你手下的 AI Agent（agy, Claude, Copilot）是你的琴键与管弦乐手。SoloMap 就是你的乐谱和指挥棒，让独立开发成为一场行云流水的**个人独奏会**。
*   **契合点**：完美契合项目中的 **“Agent Orchestrator (智能体编排/调度)”** 实现。把冰冷的开发工具升华成高审美的艺术创作，非常能打动有情怀的独立开发者。

#### 2. 独道 / 独道罗盘 (SoloMap)
*   **字面拆解**：“独”代表独立创始人；“道”代表 Roadmap（路径、正道、方法论）。
*   **品牌寓意**：谐音“独到”（意为独特、精深）。这不仅是一个工具，更是独立开发者通往商业成功、实现闭环的**独特路径与指路罗盘**。
*   **契合点**：直击方法论中的 `Build -> Sell -> Learn -> Improve` 四阶段商业闭环。

---

### 维度 B：掌控感与力量感 —— 强调“不丢方向、视觉驾驶舱”
> **打消用户对 AI 乱改代码的失控焦虑，给予创始人绝对的本地掌控感。**

#### 3. 独舵 / 独舵 AI (SoloHelm)
*   **字面拆解**：“独”代表一人，“舵”是控制航向的舵轮。
*   **品牌寓意**：在 AI 时代的信息洪流中，由你亲自掌舵。SoloMap 就是那个帮你稳定船头、对准航线（Roadmap）的**主舵机**。
*   **契合点**：对应产品的 `Cockpit (驾驶舱)` 定位，强化“本地优先、保留控制、不迷失方向”的承诺。

#### 4. 独控台 (SoloConsole)
*   **字面拆解**：“独”代表单兵作战，“控台”指控制面板与集成台。
*   **品牌寓意**：极客感十足的直观名称。将零散的终端 Agent 聚合在一个清爽高审美的控制台内。
*   **契合点**：对应 VS Code 本地控制面板的形态，凸显工具的硬核效率属性。

---

### 维度 C：直观与功能导向 —— 强调“地图导航、路径指引”
> **以最直观的语言降低用户认知负担。**

#### 5. 独航 / 独航罗盘 (SoloNav)
*   **字面拆解**：“独”代表一人，“航”代表导航、引航。
*   **品牌寓意**：为独自启航的开发者提供精准的路线图导航，摆脱“乱聊地狱”，让每一个动作都朝着可交付的里程碑前进。
*   **契合点**：直接呼应 `Visual Coding Roadmap` 核心功能。

#### 6. 独行路图 (Solo Roadmap / SoloMap)
*   **字面拆解**：“独行”意为独自前行，精准呼应 Solo Developer；“路图”即路线图（Roadmap）。
*   **品牌寓意**：为孤独的软件创业者、独立开发者量身定制的前行地图。强调“同理心与陪伴感”，在无人并肩的独行路上，为您标明每一个清晰的落脚点。
*   **契合点**：直译并信雅达地还原了 `Solo Roadmap` / `SoloMap` 的核心词根。

## 🎯 我们的最终看法与推荐

如果追求**极致的审美调性与独立创作者（Indie Hacker）社群的自发传播**，我们强烈推荐：

> 🏆 **第一推荐：独奏 AI (Soloist)**
> 
> *   **广告语畅想**：
>     *   *“别让项目烂尾在乱聊里。带上你的 AI Agent，开启属于你一个人的产品独奏会。”*
>     *   *“独奏（Soloist）：独立开发者的 AI 项目执行驾驶舱。”*
> *   **理由**：它把原本孤独、凌乱、充满挫败感的单兵开发过程，转译成了一种**体面、优雅、具有掌控力的乐章演奏**。这与 SoloMap “把零散对话穿针引线” 的调度器（Orchestrator）本质达成了完美的哲学契合。

如果追求**直观、降低认知门槛且强调路径方法论**，我们推荐：

> 🥈 **第二推荐：独道 AI / 独道罗盘 (SoloMap)**
> 
> *   **广告语畅想**：
>     *   *“独立开发，自有独道。”*
>     *   *“独道（SoloMap）：把不确定的想法推进成真实交付的 AI 路线图。”*
> *   **理由**：完美谐音“独到”，并且将“Roadmap (道路/道)”的核心价值点融于名字之中，非常符合中文受众对于“方法论”和“成功路径”的追寻。
