# Seed Users

This file is the lightweight manual CRM for the first seed users. It keeps outreach and learning visible without adding a backend service.

## Status Buckets

| Bucket | Meaning |
| --- | --- |
| Invited | Reached out, no usage signal yet |
| Installed | Installed or opened SoloMap |
| Activated | Added a project and generated or opened a roadmap |
| Ran Agent | Ran at least one Agent or Solo conversation |
| Replied | Sent feedback, issue, comment, or direct reply |
| Retained | Came back for a second session or second feedback |

## Outreach Script

```text
你之前试了 SoloMap，我想确认它有没有真的帮你推进项目。

不用写长反馈，回我三句话就行：
1. 你有没有跑通“添加项目 -> 生成路线图 -> 跑一次 Agent”？
2. 哪一步最卡？
3. 如果我下一版只改一个地方，你希望改什么？
```

## First-Round Success Signal

The seed-user round is useful when at least 5 users reach `Activated`, at least 3 users reach `Ran Agent`, and repeated friction points are clear enough to shape the next Improve loop.
